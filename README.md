# KET family practice mirror

A standalone, browser-local family practice page, updated 2026-10-21.

Flow: choose a local name → exam introduction → control examples → Listening / Speaking / Reading / Writing.

- Reading: native text, one question at a time, complete shared passages, seven groups / 44 questions.
- Writing: two source prompts, original story pictures, typed drafts or paper-photo handoff.
- Speaking: source prompts and picture task, microphone recording or local audio file, replay, immutable first submission, separate audio download.
- Listening: unavailable until matching qualified audio is supplied.
- Local profiles, draft restore, first-submission lock, answer card, copy / TXT / JSON export.

Names are local labels, not authentication. Responses and audio stay in the current browser (localStorage / IndexedDB); they are not uploaded or synchronized across devices. JSON contains audio metadata, not the audio file. Export files regularly. Browser restrictions may prevent durable storage; follow the displayed save status.

Public source questions/images are displayed with the owner's explicit publication authorization and source attribution. This is not an official Cambridge assessment or a copyright licence certification. The child page contains no answer key. No automatic Cambridge scores, proficiency levels, pass probability, AI grading or autonomous adaptive selection are provided. The parent / GPT chooses the next group after reviewing actual exported responses.

Opening this public page does not automatically share local names, responses or recordings. Same-browser users can select any local name; local profiles do not provide account access control. Old anonymous records remain unassigned and can be separately exported.
