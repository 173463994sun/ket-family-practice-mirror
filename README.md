# KET family assessment mirror

Parent phone/contact registration, multiple children per family, private cloud
progress, objective source-key agreement and pending-review results.

Ordinary families do not need an email address or verification email. They enter
a child display name and parent mobile number only. No participant password is required.
The device keeps a standard private session; another device uses a parent-held
private resume link, generated on the signed-in family page. Links last 30 days;
reissuing invalidates the old link for future use, not existing device sessions.
The phone is self-reported contact information, not verified ownership or real-name
identity. Knowing a number alone cannot retrieve historical records. Resume links must
remain with the family and are never included in answer exports or public logs.
The existing owner's administrator account has a separate collapsed login.

Content preserved: seven native-text reading groups / 44 questions, two writing
tasks with required images, one Test 2 Listening Part 2 group / five questions
with the already authorized 241-second source recording, and real speaking
prompts/pictures. Speaking recording remains optional and device-local.

Per-child drafts, first submitted answers, source references and conditions are
saved privately through Supabase. A saved message requires a server revision
acknowledgement. Concurrent edits do not silently overwrite another device.
Ordinary parents can access only their own children. The explicitly approved
operator can search parent phone and child, inspect actual responses and export
CSV/JSON. This site stores assessment records; other-module practice is excluded.

Objective results mean agreement with reviewed local source keys, not official
Cambridge scores. Writing, speaking and unlisted open-answer variants remain
pending review, never fabricated zero scores. Source keys remain server-side.
Next-group selection continues through parent/GPT review of complete-group
responses and conditions; no calibrated adaptive algorithm is claimed.

Public source display follows the owner's existing publication authorization;
this is not publisher licence certification or an official Cambridge service.
No server key, reference key registry, private child data or technical fixture
is published in this repository.
