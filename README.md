# KET open practice page

Live website: https://173463994sun.github.io/ket-family-practice-mirror/

The Owner explicitly authorized removing encryption and publishing the existing question pages and images on 2026-10-21. The current page opens directly without a login, decryption key, or HTML download. Earlier commits retain the former encrypted version as revision history.

The page includes seven Reading groups (44 questions), two Writing tasks, Speaking preparation, and a Listening entry that stays unavailable until matching audio is provided. It contains no embedded answer keys, model answers, real child responses, or credentials.

Draft saving, immutable first submissions, copy, TXT and JSON export are retained. Responses stay in each device/browser's localStorage and are never automatically uploaded; progress does not sync between computer and iPad. The existing storage namespace is preserved so browser-local responses from the previous encrypted mirror can still be restored.

This is a lightweight practice page. The next group is confirmed by GPT or a parent, not automatically graded or selected. Formal item admission, statistical calibration and official score estimates remain unperformed.
